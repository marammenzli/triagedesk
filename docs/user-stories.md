# User Stories

## User (employee)
1. As a user, I want to create a ticket with a title, description and priority, so support knows what I need.
2. As a user, I want to see my tickets and their status, so I know what's happening.
3. As a user, I want to comment on my ticket, so I can add information.

## Agent (support staff)
4. As an agent, I want to filter open tickets by priority, so I handle urgent ones first.
5. As an agent, I want to change a ticket's status, so everyone sees the progress.
6. As an agent, I want to assign a ticket to an agent, so someone owns it.
7. As an agent, I want to reply with comments, so the user gets an answer.

## Admin
8. As an admin, I want to create and update agent profiles (team, skills), so assignment is smart.
9. As an admin, I want to deactivate an agent, so they stop receiving tickets.

## Later phases
10. As a user, I want to log in securely, so only I see my tickets. (week 2 — Keycloak)
11. As an agent, I want the system to suggest a priority and category, so triage is faster. (week 6 — AI)
12. As a developer, I want the whole system to start with one command, so anyone can run it. (Docker Compose)
